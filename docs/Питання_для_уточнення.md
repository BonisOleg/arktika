# Питання для уточнення — інтернет-магазин Arctica

**Додаток до карти сайту** (`Карта_сайту_для_клієнта.md`)
**Дата:** 25.08.2026

Перелік складено на основі ТЗ (Золотова) та затвердженої карти сайту. Відповіді потрібні для проєктування бази даних і подальшої розробки. Там, де це можливо, наведено рекомендований варіант за замовчуванням.

---

## 1. Бренд і домен

- **1.1.** Остаточна назва сайту/бренду — **Arctica**, чи інша?
- **1.2.** Домен сайту вже зареєстровано? Який саме?
- **1.3.** Хостинг/сервер — вже орендований, чи потрібна допомога з вибором? (ТЗ §7.3 — розгортання на сервері Замовника)
- **1.4.** Чи є готовий логотип і фірмові кольори (брендбук)? Якщо ні — орієнтуємось на стиль rk-arctica.com.ua?

## 2. Каталог і товари

- **2.1.** Категорії — підтверджуємо 8 категорій за зразком rk-arctica.com.ua (копчена, вʼялена, пресерви, солена, салати, ікра, снеки, морожена)? Потрібні підкатегорії чи ні?
- **2.2.** Модифікації товару (ТЗ §3 «зміна ціни/артикулу при зміні модифікації») — це вага/фасування, смак, чи інше? Приклад для 2–3 товарів.
- **2.3.** Одиниці виміру — кг, упаковка, штука? Однакові для всіх категорій чи різні?
- **2.4.** Тестове наповнення (15–20 SKU, ТЗ §7.1) — товари, фото, описи, ціни надасть Замовник, чи потрібна допомога з підготовкою?
- **2.5.** Хто є джерелом фото товарів — власні професійні фото, чи потрібна обробка/добір?
- **2.6.** Як плануєте наповнювати каталог після запуску: лише вручну через адмінку, імпорт з Excel/CSV, чи синхронізація з іншою системою (1С, ERP, оптовий сайт)? Якщо імпорт/синк — це поза базовим ТЗ і обговорюється окремо.

## 3. Ціни та наявність

- **3.1.** Ціни на сайті — з ПДВ чи без?
- **3.2.** Валюта — лише гривня?
- **3.3.** Наявність товару — просте «в наявності / немає в наявності», чи потрібна точна кількість на залишку?
- **3.4.** Чи плануються знижки/акційні ціни на товар (навіть якщо окремої сторінки «Акції» немає в MVP)?
- **3.5.** Мінімальна сума замовлення — чи є обмеження?

## 4. Доставка

- **4.1.** Який провайдер доставки — Нова Пошта, чи інший (ТЗ §4.1 наводить UPS/DHL/Nova Poshta як приклад)?
- **4.2.** Регіон доставки — лише Україна?
- **4.3.** Чи потрібен самовивіз як окрема опція в checkout?
- **4.4.** Доставка платна для покупця чи безкоштовна від певної суми?
- **4.5.** Доступи до API провайдера доставки — коли зможете надати (ТЗ §4.4)?

## 5. Оплата

- **5.1.** Який платіжний провайдер — WayForPay, Stripe, PayPal чи інший (ТЗ §4.2 — приклад)?
- **5.2.** Потрібна лише онлайн-оплата карткою, чи також накладений платіж / оплата при отриманні?
- **5.3.** Мерчант-акаунт і ключі платіжної системи — коли зможете надати?

## 6. Кошик і оформлення замовлення

- **6.1.** Оформлення замовлення — лише як гість, чи потрібна реєстрація/особистий кабінет у майбутньому? (У поточному MVP кабінету немає — підтверджуємо.)
- **6.2.** Кошик — потрібна і спливаюча версія, і окрема сторінка `/cart/`, чи достатньо чогось одного?

## 7. Сповіщення

- **7.1.** Telegram-бот — вже створений? Токен бота та Chat ID/канал для сповіщень (ТЗ §4.5) — коли надасте?
- **7.2.** Окрім Telegram, чи потрібні email-сповіщення клієнту й менеджеру про нове замовлення?
- **7.3.** Хто відповідальний за обробку замовлень — один менеджер чи декілька (впливає на права доступу в адмінці)?

## 8. Контент

- **8.1.** Тексти для сторінок «Про нас», «Доставка і оплата», «Оферта», «Політика конфіденційності» — коли будуть готові? (ТЗ §7.2 — інакше тимчасовий текст-заповнювач)
- **8.2.** Юридичні документи (оферта, політика конфіденційності) — готові юристом Замовника, чи потрібен шаблон?
- **8.3.** reCAPTCHA — потрібно створити ключі Google reCAPTCHA для форм (ТЗ §2.6); хто це робить — Замовник чи Виконавець?

## 9. Мова та адмінка

- **9.1. Підтверджено:** сайт двомовний — українська (за замовчуванням, URL без префіксу) + російська (URL з префіксом `/ru/`).
- **9.2.** Тексти товарів (назва, опис, характеристики) — надаються одразу двома мовами, чи спершу лише українською з перекладом пізніше?
- **9.3.** Чи потрібен переклад юридичних сторінок (оферта, політика конфіденційності) на російську, чи достатньо української версії?
- **9.4.** Скільки акаунтів менеджерів потрібно в адмінці на старті?
