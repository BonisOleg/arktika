## 🌐 Мовна структура (i18n)

ТЗ §3 вимагає перемикач мов у шапці, §5.3 — керування перекладами в адмінці. Узгоджені мови: **uk (за замовчуванням) + ru**.

**URL-схема (рекомендований дефолт, canonical/SEO-практика):**

| Мова | Префікс URL | Приклад |
|------|-------------|---------|
| uk (default) | без префіксу | `/catalog/kopchena-ryba/` |
| ru | `/ru/` | `/ru/catalog/kopchena-ryba/` |

- Slug категорій/товарів — той самий для обох мов (перекладається лише назва/опис), якщо Замовник не вимагає окремих slug на мову.
- `hreflang` self-referencing на кожній сторінці для обох мов ([[seo_skill]] §6).
- `sitemap.xml` включає обидва мовні варіанти URL.
- Перемикач мов у шапці — на кожній публічній сторінці, зберігає поточний URL (категорія/товар), не скидає на головну.
- Переклад товарів/категорій/CMS-сторінок — керується в адмінці (ТЗ §5.3).

**Потребує підтвердження Замовника:** чи є вже готові тексти/переклади product-контенту російською, чи весь контент спершу вводиться українською, а переклад додається пізніше (впливає на дедлайн наповнення каталогу, ТЗ §7.1/7.2).
