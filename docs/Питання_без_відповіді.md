## Дійсно відкрито (немає відповіді або незрозуміло клієнту)

### 4. Доставка

- **4.4.** Доставка платна для покупця чи безкоштовна від певної суми? — без відповіді.
- **4.5.** Доступи до API провайдера доставки (Нова Пошта, «Бізнес-кабінет») — клієнт не зрозумів питання. **Потрібне пояснення:** зареєструвати бізнес-акаунт на my.novaposhta.ua → розділ «Розробникам» → згенерувати API-ключ → надати нам.

### 5. Оплата

- **5.2.** Потрібна лише онлайн-оплата карткою (WayForPay), чи також накладений платіж / оплата при отриманні?
- **5.3.** Мерчант-акаунт WayForPay і ключі (merchant login, secret key) — коли зможете надати?

### 6. Кошик і оформлення замовлення

- **6.1.** Оформлення замовлення — лише як гість, чи потрібна реєстрація/особистий кабінет у майбутньому? (У поточному MVP кабінету немає — підтверджуємо.)

### 7. Сповіщення

- **7.1.** Telegram-бот — вже створений? Токен бота та Chat ID/канал для сповіщень — коли надасте?
- **7.2.** Окрім Telegram, чи потрібні email-сповіщення клієнту й менеджеру про нове замовлення?
- **7.3.** Хто відповідальний за обробку замовлень — один менеджер чи декілька (впливає на права доступу в адмінці)?

### 8. Контент

- **8.1.** Тексти для сторінок «Про нас», «Доставка і оплата», «Оферта», «Політика конфіденційності» — коли будуть готові? (Інакше — тимчасовий текст-заповнювач.)

- **8.3.** reCAPTCHA — потрібно створити ключі Google reCAPTCHA для форм; хто це робить — Замовник чи Виконавець?

### 9. Мова та адмінка

## Не блокує старт кодування

Nova Poshta (4.4/4.5) і WayForPay (5.2/5.3) — реалізуються через stub/sandbox без реальних ключів (`novaposhta_skill` Фаза 0.5, WayForPay sandbox-режим). Telegram/email/reCAPTCHA — env-gated, вимикаються без секретів. Контент інфосторінок (8.1/8.2) — тимчасовий текст-заповнювач до надання Замовником. Блокує лише **live-запуск** відповідних модулів, не розробку.
