# Правки клієнта — головний екран

**Дата:** 2026-08-27  
**Джерело:** усний / письмовий фідбек по макету головної

## Проблема

Клієнту не подобається «порожній» фон hero (градієнт без продуктової візуалізації).

## Рішення

Розділити перший екран на дві частини:

### Ліва частина
- Залишити логотип «Арктика»
- Замінити текст на:
  - **Заголовок:** Риба яку ми робимо самі
  - **Підзаголовок:** Коптимо, солимо та в’ялим. Доставляємо по Україні.
- Кнопки «Перейти до каталогу» та «Дивитись хіт» залишити під текстом

### Права частина
Яскрава композиція з продуктів:
- червона ікра
- чорна ікра
- юкола форелі
- копчена скумбрія

## Додаткові вимоги до макету

- Текст — з великої літери на початку речень
- Фото в макеті мають відповідати реальним продуктам (не випадкові стоки)
