**Дата:** 25.08.2026
**Мови сайту:** українська (за замовчуванням) + російська

---

## 1. Загальна концепція

Роздрібний інтернет-магазин рибної продукції. За візуальний та товарний орієнтир взято сайт [rk-arctica.com.ua](https://rk-arctica.com.ua/) — але той сайт працює на **опт** (заявки, без оплати онлайн). Наш сайт орієнтований на **роздріб**: повний цикл — каталог → кошик → оформлення замовлення → онлайн-оплата.

## 3. Мовна версія сайту

Сайт двомовний: **українська (за замовчуванням) і російська**.

Кожна сторінка каталогу й товару матиме дві мовні адреси, наприклад:
- Українською: `/catalog/kopchena-ryba/`
- Російською: `/ru/catalog/kopchena-ryba/`

Перемикач мов — у шапці сайту. Назви, описи та характеристики товарів можна вести окремо для кожної мови.

## 4. Що НЕ входить у цей етап

Щоб уникнути непорозумінь під час приймання робіт, окремо фіксуємо, чого немає в базовому обсязі:

- Особистий кабінет покупця
- Список бажань / порівняння товарів
- Блог або сторінка з рецептами
- Окрема сторінка «Акції» (блоки хітів і новинок є на головній)
- Окрема сторінка «Для гуртових клієнтів» (лише посилання на сторінці «Контакти» на rk-arctica.com.ua)

Якщо будь-що з цього переліку потрібне — це можна додати окремою домовленістю до Договору.
